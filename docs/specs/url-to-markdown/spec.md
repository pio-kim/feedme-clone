# URL을 Markdown으로 바꿔 LLM에 넘기기

웹 페이지 URL을 붙여넣으면 본문만 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 프롬프트를 붙여 ChatGPT·Claude로 바로 넘긴다.

## 함께 읽을 자료

- [prototype.html](prototype.html): 승인된 화면. 변환기 화면의 구성, 상태(기본·변환 중·변환 실패·결과), 프롬프트 선택과 내보내기 동작, 좁은 화면과 다크모드에서의 배치를 정한다.
- [UI 구성 원칙](../../decisions/ui-composition.md): 컴포넌트 선택, semantic token, 상태 표현 규칙을 정한다.

## 사용자가 얻는 결과

- URL 하나로 광고·메뉴 없이 본문만 담긴 Markdown을 얻는다.
- 결과를 클립보드나 `.md` 파일로 가져가거나, 원하는 요청과 함께 ChatGPT·Claude 새 채팅으로 바로 연다.

## 범위

1. **입력:** URL 입력칸, 입력 지우기 버튼, 변환 버튼.
2. **변환:** 서버가 페이지를 받아 defuddle로 본문을 Markdown으로 추출한다. defuddle 사용은 필수 조건이다.
3. **결과 확인:** 페이지 제목, 저자·사이트, 원문 링크로 된 헤더와 렌더링된 Markdown.
4. **내보내기:** 복사하기, `.md` 다운로드, ChatGPT로 열기, Claude로 열기.
5. **프롬프트:** 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력". 고른 프롬프트를 LLM에 넘기는 본문 앞에 붙인다.
6. **다크모드 토글.**

## 수용 기준

- URL이 비어 있으면 변환 버튼이 비활성이다. 입력이 있으면 지우기 버튼이 보인다.
- 지우기를 누르면 입력, 결과, 오류, 프롬프트 선택이 모두 처음 상태로 돌아간다.
- 변환 중에는 버튼에 진행 표시가 나오고 다시 누를 수 없으며, 결과 자리에 로딩 모양이 보인다.
- 변환에 실패하면 결과 대신 이유가 담긴 오류 안내가 보인다. 형식이 잘못된 URL, http·https가 아닌 URL, 불러오기 실패(HTTP 상태 포함), 본문 없음을 구분해 알린다.
- 변환에 성공하면 제목과 저자·사이트, 원문 링크가 헤더에 보이고 그 아래에 Markdown이 제목, 목록, 코드 블록, 표, 인용까지 렌더링된다.
- 복사하기와 `.md` 다운로드는 같은 문서를 내보낸다. 문서는 제목, 저자, 출처 URL을 담은 머리말과 본문 Markdown으로 이루어진다. 복사가 끝나면 알림이 뜬다.
- 프롬프트는 하나만 고를 수 있고, 고른 것을 다시 누르면 선택이 풀린다. 아무것도 고르지 않으면 본문만 넘어간다.
- "직접 입력"을 고르면 텍스트 입력칸이 나타나고, 입력한 내용이 프롬프트로 쓰인다.
- ChatGPT·Claude로 열기를 누르면 새 탭에서 새 채팅이 열리고, 프롬프트와 문서가 입력된 상태로 시작한다.
- 다크모드 토글로 밝은 테마와 어두운 테마를 오갈 수 있다.
- 좁은 화면(390px)에서는 입력칸과 변환 버튼이 세로로 쌓이고, 내용이나 버튼이 화면 밖으로 넘치지 않는다.

## 정해진 제약과 이유

- **본문 추출은 defuddle로 한다.** 사용자가 정한 필수 조건이다.
- **직접 입력한 프롬프트는 저장하지 않는다.** 한 번만 쓰는 용도로 정해졌다. 새로 변환하거나 지우면 사라진다.
- **페이지는 서버에서 가져온다.** 브라우저에서 다른 사이트의 HTML을 직접 받을 수 없기 때문이다.
- **LLM으로 넘길 때 URL에 담을지는 글자 수 6,000자로 정한다.** 프롬프트와 문서를 합친 메시지가 이보다 길면 전체 메시지를 클립보드에 복사하고, 빈 새 채팅을 연 뒤 붙여넣으라고 안내한다. 인코딩한 URL 길이로 바꾸는 안도 검토했지만, 리뷰에서 지금 기준을 유지하기로 했다.
- **본문의 이미지는 남긴다.** 결과 화면은 원래 사이트의 이미지를 그대로 보여 주고, 복사·다운로드·LLM에 넘기는 문서에도 이미지 주소가 들어간다. 그래서 결과를 보는 사람의 브라우저가 원래 사이트에 이미지를 직접 요청한다. 리뷰에서 이미지를 빼는 안과 비교한 뒤 원래 글에 가까운 모습을 유지하기로 했다.

## 가정 (바꿀 수 있는 기본값)

- 스킴 없이 입력한 URL(`example.com/a`)은 `https://`를 붙여 처리한다.
- 페이지 가져오기는 15초가 지나면 실패로 본다.
- LLM으로 넘기는 메시지는 "프롬프트, 구분선(`---`), 문서" 순서다.
- 다운로드 파일 이름은 글 제목에서 파일 이름에 쓸 수 없는 문자를 빼고 만든다. 제목이 없으면 `page.md`를 쓴다.
- 저자와 사이트 이름이 같으면 헤더에 한 번만 보여 준다.
- 다크모드는 처음에 시스템 설정을 따른다.
- 선택된 프롬프트는 primary 색으로 칠해 구분한다.

## 범위 밖

- 직접 입력 프롬프트나 변환 기록의 저장. 1회용으로 정해졌다.
- 로그인, 계정, 사용량 제한.
- JavaScript로 그려지는 페이지나 로그인이 필요한 페이지의 본문 추출. 서버가 받은 HTML만 다룬다.
- 프로젝트 예산에 없는 보안 하드닝(내부망 주소 차단 등)과 성능 방어.

## 미룬 것

- 없음.

## 남은 위험

- 6,000자 기준은 글자 수라서 한글이 많은 글은 URL이 훨씬 길어진다. 6,000자에 가까운 한국어 메시지는 약 54KB URL이 되는데, ChatGPT·Claude가 이 길이를 받아 주는지는 확인하지 않았다.
- ChatGPT·Claude의 `q` 파라미터 동작은 두 사이트가 정한다. 사이트가 동작을 바꾸면 "열기"에서 내용이 채워지지 않을 수 있다.
- 일부 사이트는 서버의 요청을 막거나(403 등) 본문 대신 차단 페이지를 돌려준다. 이때는 변환 실패나 엉뚱한 본문이 나온다.
- 서버가 사용자가 입력한 아무 주소에나 요청을 보낸다. 공개 배포 전에는 내부망 주소 차단을 다시 검토해야 한다.
