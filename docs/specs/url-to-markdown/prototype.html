LLM으로 열기

React 팀이 10월 7일 React 컴파일러 1.0을 정식으로 내놓았습니다. 2024년 5월 첫 베타가 나온 지 1년 5개월 만입니다. 컴파일러는 빌드 단계에서 컴포넌트를 분석해, 지금까지 개발자가 손으로 넣던 useMemo, useCallback, React.memo를 자동으로 끼워 넣습니다.

무엇이 달라지나

사내 대시보드 3개(컴포넌트 1,284개)에 적용해 본 결과, 수동 메모이제이션 코드의 약 71%를 지워도 렌더링 횟수가 그대로였습니다. 상호작용 지연(INP)은 p75 기준 212ms에서 168ms로 줄었습니다.

  • props가 바뀌지 않은 자식 컴포넌트의 재렌더링을 자동으로 건너뜁니다.
  • 렌더링 중 계산한 파생 값은 입력이 같으면 다시 계산하지 않습니다.
  • 이벤트 핸들러를 매번 새로 만들지 않아 useCallback이 대부분 필요 없어집니다.

설정 방법

Next.js 16부터는 설정 한 줄이면 됩니다.

// next.config.ts
const nextConfig = {
  reactCompiler: true,
};

export default nextConfig;

아직 지우면 안 되는 경우

상황이유대안
외부 라이브러리에 넘기는 콜백컴파일러가 라이브러리 내부 비교를 알 수 없음useCallback 유지
렌더링 중 ref 읽기규칙 위반으로 해당 컴포넌트 최적화 생략effect로 이동
10,000행 이상 목록 정렬비용이 커서 명시적 의도 표시가 낫다useMemo 유지
컴파일러는 규칙을 지키는 코드만 최적화합니다. 먼저 eslint-plugin-react-compiler로 경고를 0개로 만드세요.

자세한 마이그레이션 순서는 공식 블로그 글에 정리되어 있습니다.
